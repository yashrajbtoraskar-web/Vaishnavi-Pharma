## 🚀 How to Deploy on GitHub Pages

### Step 1 — Delete old repo (if flagged as dangerous)
1. Go to **GitHub.com** → Your Repository → **Settings**
2. Scroll down to the bottom → **Danger Zone**
3. Click **"Delete this repository"** → confirm

### Step 2 — Create a new repository
1. Go to **github.com/new**
2. Name it exactly: `Vaishnavi-Pharma` (same name)
3. Set it to **Public**
4. ✅ Check **"Add a README file"** → then click **Create repository**

### Step 3 — Upload your files
1. Click **"Add file"** → **"Upload files"**
2. Drag and drop ALL these files:
   - index.html, medicines.html, prescription.html
   - cart.html, contact.html, styles.css, script.js, README.md
3. Scroll down → Click **"Commit changes"**

### Step 4 — Enable GitHub Pages
1. Go to **Settings** → **Pages** (left sidebar)
2. Under **Source** → select **"Deploy from a branch"**
3. Branch: **main** → Folder: **/ (root)** → Click **Save**
4. Wait 2–3 minutes → your site will be live at:
   `https://yashrajbtoraskar-web.github.io/Vaishnavi-Pharma/`

### Step 5 — Deploy on Vercel (optional but recommended)
1. Go to **vercel.com** → Sign in with GitHub
2. Click **"Add New Project"**
3. Select your `Vaishnavi-Pharma` repository
4. Click **Deploy** — done! Vercel gives you a faster, safer URL.

## ⚠️ Why was my site flagged as "Dangerous"?
GitHub Pages sites can sometimes get flagged by Google Safe Browsing if:
- The old repository had a security issue reported
- The domain was previously reported

**Solution:** Delete the old repo and create a fresh one with the same name. The new URL will be clean.
